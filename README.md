# Reaper Control

A stage controller for the REAPER DAW: plays a setlist live, switches songs on time, and stays out of the way.

This is the v2 rewrite (Rust + Tauri + Svelte, with a native REAPER extension). It is in the planning and early build phase. The previous Electron version lives in a separate repository.
