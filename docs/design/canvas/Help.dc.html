Songs and markers in REAPER

Every region in your project is a song. Press Shift + R to create one. Every marker (press M) becomes a point you can jump to from the timeline.

Special markers

Add these to a marker name to change how a song behaves. Place the marker within 0.001 seconds of the region start or end. Special markers are hidden from the timeline.
